## 使用

在 GitHub 中从章节目录开始阅读；也可以克隆仓库后，在 Obsidian 中打开这个文件夹。原笔记中少量指向原有知识库的双链保持原样，独立阅读时可使用上面的直接链接。

`images/` 保存正文图片及代码 OCR 的原图；`.marker/` 保存转换脚本和校验记录。转换过程的旧备份未纳入仓库。

本仓库保留导入时的原文及转换记录，OCR 和排版内容仍可能需要人工校对。
