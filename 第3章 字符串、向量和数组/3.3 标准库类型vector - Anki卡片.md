### 基础概念

#### 01 · 原理 · 3.3

**正面**

`vector<T>` 中的元素类型有什么共同要求？

> [!answer]- 背面
> 所有元素都是 **`T` 类型的对象**；每个元素可以用索引访问。
>
> 例如 `vector<int>` 存放 `int`，`vector<string>` 存放 `string`。

#### 03 · 原理 · 3.3

**正面**

在本节的 C++11 语境下，为什么不能只写 `vector v;`，而要写 `vector<int> v;`？

> [!answer]- 背面
> `vector` 是**类模板**，不是一个具体类型；必须提供元素类型等模板实参。
>
> `vector<int>` 才是具体类型。编译器根据模板生成具体类的过程叫**实例化**。

#### 07 · 原理 · 3.3.1

**正面**

直接用另一个 `vector` 拷贝初始化时，两个容器的类型有什么要求？

```cpp
vector<int> a{1, 2};
vector<int> b = a;
vector<string> c = a;
```

> [!answer]- 背面
> 在本节这种**整个容器的拷贝初始化**中，容器类型必须相同。
>
> `b` 合法，包含 `1, 2` 的副本；`c` 不合法，`vector<int>` 不能直接拷贝成 `vector<string>`。
>
> 对这里的 `int` 元素，修改 `b` 中的值不会改变 `a`。

#### 10 · 原理 · 3.3.1

**正面**

下面两个容器的元素数量和内容有什么区别？

```cpp
vector<int> a(10);
```

#### 11 · 原理 · 3.3.1

**正面**

下面两个容器的元素数量和内容有什么区别？

> [!answer]- 背面

#### 12 · 原理 · 3.3.1

下面的 `v` 包含几个元素？为什么不是 1 个？

#### 14 · 原理 · 3.3.1

**正面**

下面的定义合法吗？若想创建 10 个值为 0 的 `int` 元素，应怎样修改？

> [!answer]- 背面
> 不合法。不能用整数 `10` 隐式转换得到整个 `vector<int>`。

#### 15 · 原理 · 3.3.1

**正面**

如果类型 `T` 不能默认构造，还能直接写 `vector<T> v(n);` 创建 `n` 个元素吗？（`n > 0`）

> [!answer]- 背面
> 不能用这种“只给数量”的方式创建这些元素，因为它需要对元素进行默认构造／值初始化。

> 应给出可用的元素初值；例如在 `T` 可拷贝等条件满足时：
>
> ```cpp

> ```

### 添加元素与增长

#### 16 · 原理 · 3.3.2

**正面**

对 `vector<int> v{1, 2};` 执行 `v.push_back(9);` 后，元素顺序和 `size()` 分别是什么？

> [!answer]- 背面
> 元素依次为 **`1, 2, 9`**，`size()` 为 **3**。
>
> `push_back` 在**尾端添加一个新元素**，不是覆盖最后一个元素。

读入的整数数量事先未知时，怎样把所有成功读入的值存入一个 `vector`？

#### 19 · 练习 · 3.3.2

**正面**

下面代码执行后，`v` 的完整内容是什么？

```cpp
vector<int> v(3);
for (int i = 1; i <= 3; ++i)
```

>
> 若只想得到 `1, 2, 3`，从空 `vector<int> v;` 开始。

#### 20 · 原理 · 3.3.2

**正面**

元素数量未知、值需要逐个获得时，适合怎样构造 `vector`？何时适合直接指定数量和统一初值？

> [!answer]- 背面
> - 数量未知、值逐个获得：**先创建空容器，再 `push_back`**。
> - 需要 `n` 个相同初值：例如 `vector<int> v(n, 42);`。
>
> `vector` 支持高效增长；不要为了“占位置”先创建一批不需要的元素。
>
> 这不是“预先确定大小在所有程序里都更慢”的性能定律。

### 遍历与引用

#### 21 · 原理 · 3.3.2

**正面**

下面的范围 `for` 用法为什么不安全？

```cpp
for (auto x : v)
    v.push_back(x);
```

> [!answer]- 背面
> 它在遍历 `v` 的同时**改变了 `v` 的大小**，会使循环所依赖的迭代状态失效，不能这样使用。
>
> 范围 `for` 体内可以修改已有元素的值，但**不应增删正在遍历的容器的元素**。

#### 22 · 原理 · 3.3.3

**正面**

为什么下面的代码不能把 `vector<int> v` 中的元素都平方？怎样改？

```cpp
for (auto x : v)
    x *= x;
```

> [!answer]- 背面
> `x` 是元素的**副本**，修改它不会修改 `v`。
>
> 改用引用：
>
> ```cpp
> for (auto &x : v)
>     x *= x;
> ```
>
> 此时 `x` 绑定到原元素。这里假定平方结果不超出 `int` 的范围。

#### 24 · 原理 · 3.3.3

**正面**

`v.empty()` 和 `v.size()` 分别返回什么？`vector<int>` 的 `size_type` 应怎样完整书写？

> [!answer]- 背面
> - `v.empty()`：没有元素时返回 `true`，否则为 `false`。
> - `v.size()`：返回**已有元素个数**，类型是对应容器的 `size_type`。
>
> ```cpp

> ```
>
> 它是无符号整数类型。不能写 `vector::size_type`，因为缺少元素类型。

### 相等与字典序

#### 26 · 原理 · 3.3.3

**正面**

在元素支持相等比较的前提下，两个同类型的 `vector` 何时相等？

> [!answer]- 背面
> 必须同时满足：
>
> 1. **元素个数相同**。
> 2. **对应位置的元素值全部相等**。
>
> 例如 `{1, 2}` 和 `{2, 1}` 不相等；只看“包含相同的值”不够。

#### 27 · 原理 · 3.3.3

**正面**

下面的比较结果是什么？为什么不能只比较元素个数？

```cpp
vector<int> a{1, 100};
vector<int> b{2};
bool result = a < b;
```

> [!answer]- 背面
> **`true`**。
>
> `vector` 按**字典序**比较：第一对不同的元素决定大小。这里首元素 `1 < 2`，所以 `a < b`，即使 `a` 的元素更多。

#### 28 · 原理 · 3.3.3

**正面**

按字典序比较时，如果一个 `vector` 是另一个的完整前缀，哪个更小？


> [!answer]- 背面
> **较短的更小**，因此 `a < b`。
>

#### 29 · 原理 · 3.3.3

**正面**

在本节的 C++11 语境下，是否所有 `vector<T>` 都能使用 `==` 和 `<` 比较？

> [!answer]- 背面
> 不是。元素类型 `T` 必须支持相应的比较操作：
>
> - 比较容器是否相等，需要元素能做相等比较。
> - 比较容器的字典序大小，需要元素能做相应的大小比较。
>
> 不能因为 `T` 能放进容器，就认为它一定能参与所有容器比较。

### 下标与边界

#### 30 · 原理 · 3.3.3

**正面**

对于大小为 `n` 的 `vector`，下标访问必须满足什么条件？空容器有合法下标吗？

> [!answer]- 背面
> 合法索引满足 **`0 <= i < n`**。
>
> - `n > 0` 时：下标为 `0` 到 `n - 1`。
> - `n == 0` 时：**没有任何合法下标**。
>
> `v[v.size()]` 不是最后一个元素，而是越界访问。

#### 31 · 练习 · 3.3.3 · 练习3.18

**正面**

下面代码错在哪里？怎样通过“添加元素”修正？

```cpp
vector<int> v;
v[0] = 42;
```

> [!answer]- 背面
> `v` 为空，`v[0]` 不存在。
>
> **下标只能访问已有元素，不能创建元素**。添加应写：
>
> ```cpp
> vector<int> v;
> v.push_back(42);
> ```
>
> 另一种思路是先创建元素，例如 `vector<int> v(1);`，之后才可用 `v[0] = 42;`。

#### 32 · 原理 · 3.3.3

**正面**

在 C++11 中，`vector::operator[]` 越界会保证编译报错、抛异常，还是得到某个固定值？

> [!answer]- 背面
> 都不保证。越界使用 `operator[]` 属于**未定义行为**。

>
> 必须在访问前保证下标合法。

#### 33 · 练习 · 3.3.3

**正面**

写一个对空容器也安全的下标遍历循环，输出 `vector<int> v` 的全部元素。（循环中不改变大小）

> [!answer]- 背面
> ```cpp
> for (vector<int>::size_type i = 0; i < v.size(); ++i)
>     cout << v[i] << '\n';
> ```
>
> 使用 `i < v.size()`，不要写 `i <= v.size()`。
>
> 也不要用 `i <= v.size() - 1`：`v` 为空时，无符号数 `0 - 1` 会下溢。

#### 34 · 原理 · 3.3.1 · 术语澄清

**正面**

`vector<int> v(10);` 中的 `10` 表示“已有元素数”，还是“仅预留空间、尚无元素”？

> [!answer]- 背面
> 表示**已有元素数**：`v.size() == 10`，已有 10 个值为 `0` 的元素。
>
> 不要把它等同于仅预留空间。`size()` 是元素个数；`capacity()` 是当前已分配存储最多能容纳的元素数，二者不同。
>
> 补充澄清：原笔记某些语句把元素数量称作“容量”；这里严格区分两种术语。此时只能确定 `capacity() >= 10`，不能据此断言恰好等于 10。

#### 42 · 练习 · 3.3.3 · 练习3.20

**正面**

怎样从两端向中间输出 `vector<int> v` 的配对和：首尾、次首与次尾……？约定每个元素最多使用一次，奇数个元素时中间值单独输出。（假定和不溢出）

> [!answer]- 背面
> ```cpp
> const auto n = v.size();
> for (decltype(v.size()) i = 0; i < n / 2; ++i)
>     cout << v[i] + v[n - 1 - i] << '\n';
> if (n % 2 != 0)
>     cout << v[n / 2] << '\n';
> ```
>
> 循环只处理 `n / 2` 对，不会重复配对。`n == 0` 时不会进入循环，也不会执行 `n - 1 - i`。
>
> 例如 `{1, 2, 3, 4, 5}` 输出 `6, 6, 3`；奇数情况按题面约定处理，不把中间元素加两次。
